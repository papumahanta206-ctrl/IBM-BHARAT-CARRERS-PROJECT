# IBM-BHARAT-CARRERS-PROJECT
AI-powered Data Analytics project that analyzes student academic and technical skills, predicts performance using Machine Learning, identifies skill gaps, and recommends suitable career domains. Built using Python, Pandas, NumPy, Matplotlib, and Scikit-learn.
# AI-Powered Student Performance & Career Analytics

An AI and Data Analytics project that analyzes student academic and technical-skill data to generate meaningful insights and support career planning.

## Project Overview

This project uses **Python, Data Analytics, and Machine Learning** to analyze student performance and skills. It predicts the student's performance level, identifies skill gaps, and provides career-domain recommendations based on academic and technical attributes.

## Key Features

* Student performance analysis
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Data visualization
* Machine Learning-based performance prediction
* Skill gap analysis
* AI-based career recommendation
* Interactive analysis using Jupyter Notebook
* Optional Streamlit dashboard

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook
* Streamlit
* Joblib

## Machine Learning

A **Random Forest Classifier** is used to classify students into:

* Needs Improvement
* Average
* High

The project also uses a weighted career-matching approach to recommend domains such as:

* Data Analyst
* AI/ML Engineer
* Software Developer
* Business Analyst

## Project Workflow

**Data Collection → Data Cleaning → EDA → Feature Engineering → Machine Learning → Performance Prediction → Skill Gap Analysis → Career Recommendation**

## Dataset

The project uses a synthetic student dataset containing academic performance, technical skills, projects, certifications, attendance, and internship information.

## Project Objective

The main objective is to demonstrate how **Data Analytics and Artificial Intelligence** can be combined to transform student data into useful insights for performance analysis, skill development, and career exploration.

> This project was developed as an academic project to demonstrate practical applications of Data Analytics and AI.
